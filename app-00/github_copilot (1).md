# GitHub Copilot 実装指示書：おうちコーヒー＆おやつコンシェルジュ

以下の仕様と要件に基づいて、Webアプリケーションのコードを作成してください。
ファイルは `index.html`、`style.css`、`script.js` の3つに分割して出力してください。

---

## 1. アプリケーション概要
* **アプリ名**: 今日の「おうちコーヒー＆おやつ」コンシェルジュ
* **コンセプト / Vibe**: 
  「今、自分の気分に一番合う一杯と、それに合う小さなご褒美を、占い感覚でふんわり決めてくれるお遊びアプリ」
  温かみがあり、ほっと一息つけるカフェのような、可愛らしくて優しい雰囲気（パステルカラーやカフェラテ色、角丸のカードUI）。
* **ターゲット・用途**: 自宅でコーヒータイムを楽しみたい人が、直感で3択から気分を選び、おすすめのペアリングと癒やしの猫（イラストや絵文字・メッセージ）を楽しむ。

---

## 2. 技術スタック・環境要件
* **構成ファイル**:
  1. `index.html`（画面構造、Tailwind CSSのCDN読み込み）
  2. `style.css`（カスタムアニメーション、フォント設定、Tailwindで補えない微調整）
  3. `script.js`（データ定義、ランダム抽選・条件分岐ロジック、DOM操作、LocalStorage管理）
* **CSSフレームワーク**: Tailwind CSS（CDN版を使用: `<script src="https://cdn.tailwindcss.com"></script>`）
* **データ保存**: データベースは使用せず、ブラウザの `localStorage` を使用して「過去の診断履歴（お気に入り・履歴）」を保存・表示する。
* **ホスティング前提**: GitHub Pages でそのまま公開できるよう、すべて相対パスで記述し、ビルド不要の静的ファイル構成にする。

---

## 3. 画面構成とUIデザイン要件

### 全体デザイン
* 背景色：温かみのあるクリーム色や淡いベージュ系（例: `#FDF8F5` や Tailwindの `bg-amber-50/50`）
* フォント：丸みのある優しい印象のGoogle Fonts（例: `Zen Maru Gothic` や `M PLUS Rounded 1c`）を `index.html` で読み込む。
* レイアウト：スマートフォンでもPCでも見やすい、中央寄せのカード型デザイン（最大幅 `max-w-md` 〜 `max-w-lg` 程度）。

### セクション構成
1. **ヘッダー**
   * アプリタイトルと、コーヒーカップ・猫の可愛いアイコン（絵文字やSVG）。
   * 「今の気分を直感で選んでね」という一言メッセージ。
2. **気分選択エリア（3択ボタン）**
   * ユーザーが直感で押せる大きな可愛いカード型ボタンを3つ配置。
     * 選択肢A：**「🌿 リラックスしたい」**（ほっと一息、癒やされたい気分）
     * 選択肢B：**「🍰 甘いものを食べたい」**（ご褒美、糖分チャージしたい気分）
     * 選択肢C：**「💡 集中したい」**（シャキッと切り替え、作業を頑張りたい気分）
   * ホバー時やクリック時にふわっと浮き上がるようなアニメーションを付ける。
3. **診断結果表示エリア（カード型UI）**
   * 初期状態は非表示、または「上のボタンから気分を選んでね」のプレースホルダー表示。
   * ボタンを押すと、占い結果のようにふわっとフェードインして以下の4要素を1枚の可愛いカードにまとめて表示する。
     1. **おすすめのコーヒー＆淹れ方**（例：「深煎りカフェオレ（ミルクたっぷりめ）」）
     2. **手元にあると嬉しい小さなおやつ**（例：「ひとくちサイズの生チョコ」）
     3. **お供の猫ちゃん＆ひとことメッセージ**（例：茶トラ猫のイラスト/絵文字 ＋ 「無理せずゆっくり休むにゃ〜」）
     4. **ラッキーアクション / 占い風の小さなアドバイス**（例：「お気に入りのマグカップを使うと運気アップ！」）
   * 「もう一度占う（別の組み合わせを見る）」ボタンも配置。
4. **最近の履歴エリア（LocalStorage連携）**
   * 過去に引いた「気分・コーヒー・おやつ・猫」の組み合わせを最新5件〜10件までリスト表示する。
   * 「履歴をクリア」ボタンを配置。

---

## 4. 機能・ロジック要件（`script.js`）
* **マスターデータ**:
  * 3つの気分（`relax`, `sweet`, `focus`）それぞれに対して、最低3〜4パターン以上の「コーヒー」「おやつ」「猫（キャラクター名・絵文字/SVG・セリフ）」「一言アドバイス」のバリエーションを用意する。
  * 同じ気分を選んでも、毎回少しずつ違う組み合わせが楽しめるようにランダム抽選（前回と同じ結果が連続しにくい工夫があると尚良し）を行う。
* **LocalStorage管理**:
  * キー名例: `coffee_concierge_history`
  * 診断結果が出るたびに、日時（例: `11/13 19:30`）・選んだ気分・コーヒー・おやつ・猫の情報を配列の先頭に追加して保存する。
  * ページ再読み込み時にも履歴が復元されるようにする。

---

## 5. 出力形式のお願い
VS Codeでそのままファイルを作成して貼り付けられるように、以下の順番でコードブロックを出力してください。
1. `index.html`
2. `style.css`
3. `script.js`

コード内には、後から自分で「コーヒーの種類」や「おやつ」「猫のセリフ」を簡単に追加・編集できるよう、分かりやすい日本語コメントを入れてください。
